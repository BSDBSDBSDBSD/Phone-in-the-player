# דיבורית (PhoneLink)

אפליקציה שהופכת נגן אנדרואיד עם Root לדיבורית בלוטות' של טלפון פשוט, כמו מערכת מולטימדיה ברכב:
מחייגים מהנגן, עונים לשיחות, רואים את אנשי הקשר ואת השיחות האחרונות. השיחה עצמה עוברת דרך הטלפון
(הכרטיס נשאר בו), והקול עובר בבלוטות' לנגן.

## מה צריך
- נגן עם אנדרואיד 13 ו-**Magisk** (Root).
- טלפון עם בלוטות' שתומך בדיבורית. כמעט כל טלפון עם בלוטות' תומך בזה.
  כדי שאנשי הקשר יעברו, הטלפון צריך לשתף אותם (אם הם מופיעים ברכב, זה יעבוד גם כאן).

## התקנה
1. מורידים את `PhoneLink-magisk.zip`: מהדף **Releases ← latest** בגיטהאב, או מ-**Actions** ← הבנייה האחרונה ← `PhoneLink-magisk`.
2. מעבירים את הקובץ לנגן. ב-Magisk: **מודולים ← התקן מאחסון** ובוחרים את הקובץ.
3. מפעילים מחדש את הנגן.
4. בהגדרות הבלוטות' של הנגן מצמדים את הטלפון: מחפשים מכשירים ומאשרים את הקוד בשני המכשירים.
5. פותחים את "דיבורית", מאשרים את ההרשאות, ובתפריט בוחרים **בחר טלפון**.
   אם הטלפון שואל אם לאפשר גישה לאנשי הקשר, מאשרים.

**לא להתקין את ה-APK בהתקנה רגילה.** האפליקציה חייבת לרוץ כאפליקציית מערכת, והמודול הוא שדואג לזה.

## מה המודול עושה
- מתקין את האפליקציה כאפליקציית מערכת (`/system/priv-app`) עם הרשאת בלוטות' מיוחדת.
- מפעיל בנגן את פרופילי הבלוטות' של צד הדיבורית, שכבויים בנגנים ובטלפונים:
  `bluetooth.profile.hfp.hf.enabled`, `bluetooth.profile.pbap.client.enabled` ו-`bluetooth.profile.map.client.enabled`.
- כדי לבטל: מכבים או מוחקים את המודול ב-Magisk ומפעילים מחדש.

## אם משהו לא עובד
בתפריט יש **בדיקת מערכת**. המסך בודק כל שלב ומסביר מה לתקן, וכפתור **העתק דוח** מעתיק את התוצאות כדי לשלוח אותן.
הכפתור **הפעל עכשיו עם Root** מפעיל את הפרופילים עד ההפעלה הבאה של הנגן, בלי מודול. זה טוב לבדיקה מהירה,
אבל אפליקציה שלא מותקנת דרך המודול עדיין לא תקבל את ההרשאה הנדרשת.

**הנקודה הלא ודאית: הקול.** אם החיבור והחיוג עובדים אבל לא שומעים כלום, הבעיה היא כנראה שרכיב השמע של הנגן
לא תומך בהעברת קול של שיחה בכיוון הזה. זה תלוי בדגם. כדאי לנסות את הכפתור "הקול בנגן / הקול בטלפון" במסך השיחה.

## מבנה הקוד
הקוד נמצא ב-`app/src/main/java/com/offline/phonelink/`:
- `bt/HfpClient.kt`: הגישה לממשקי הדיבורית ואנשי הקשר של אנדרואיד (ממשקים מוסתרים, דרך reflection).
- `bt/LinkService.kt`: שירות ברקע. עוקב אחרי שיחות, מצלצל, פותח את מסך השיחה ושומר היסטוריה.
- `data/`: אנשי קשר והיסטוריית שיחות. כשהטלפון מתחבר, אנדרואיד מעתיק אותם לנגן בעצמו.
- `ui/`: חייגן, אנשי קשר, אחרונות, מסך שיחה ובדיקת מערכת.
- `app/magisk/`: קבצי המודול. `./gradlew :app:packageMagiskModule` בונה את
  `app/build/outputs/magisk/PhoneLink-magisk.zip`.
